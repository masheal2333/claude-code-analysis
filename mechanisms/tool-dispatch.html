"添加工具 = 添加一个处理器"

🎯 概述

工具分发 是 Claude Code 的扩展机制。每个工具都注册到一个分发映射中，当 Claude 返回 tool_use 时，系统会查找并执行对应的工具。

核心思想：

  • 🔌 即插即用：添加新工具只需要注册到映射
  • 🏭 工厂模式：buildTool() 提供安全默认值
  • 🔒 权限控制：每个工具都有权限检查

💻 代码分析

Tool.ts - 工具定义

interface Tool {
    name: string;
    description: string;
    parameters: JSONSchema;
    execute: (params: any) => Promise<any>;
}

function buildTool(definition: ToolDefinition): Tool {
    return {
        name: definition.name,
        description: definition.description,
        parameters: definition.parameters,
        execute: async (params) => {
            // 权限检查
            await checkPermissions(definition.name, params);
            // 执行工具
            return await definition.execute(params);
        }
    };
}
from dataclasses import dataclass
from typing import Any, Callable

@dataclass
class Tool:
    name: str
    description: str
    parameters: dict
    execute: Callable[[Any], Any]

def build_tool(definition: dict) -> Tool:
    return Tool(
        name=definition["name"],
        description=definition["description"],
        parameters=definition["parameters"],
        execute=lambda params: (
            check_permissions(definition["name"], params),

tools.ts - 工具注册

// 工具注册表
const toolRegistry = new Map<string, Tool>();

// 注册工具
function registerTool(tool: Tool) {
    toolRegistry.set(tool.name, tool);
}

// 获取工具定义（用于 API 调用）
function getToolDefinitions() {
    return Array.from(toolRegistry.values()).map(tool => ({
        name: tool.name,
        description: tool.description,
        parameters: tool.parameters
    }));
}

// 执行工具
async function executeTool(toolUse: ToolUse) {
    const tool = toolRegistry.get(toolUse.name);
    if (!tool) {
        throw new Error(`Unknown tool: ${toolUse.name}`);
    }
    return await tool.execute(toolUse.input);
}
# 工具注册表
tool_registry = {}

# 注册工具
def register_tool(tool: Tool) -> None:
    tool_registry[tool.name] = tool

# 获取工具定义（用于 API 调用）
def get_tool_definitions() -> list[dict]:
    return [
        {
            "name": tool.name,
            "description": tool.description,
            "parameters": tool.parameters
        }
        for tool in tool_registry.values()
    ]

# 执行工具
async def execute_tool(tool_use: dict) -> Any:
    tool_name = tool_use["name"]
    tool = tool_registry.get(tool_name)
    if not tool:
        raise ValueError(f"Unknown tool: {tool_name}")
    return await tool.execute(tool_use["input"])

🏭 工厂模式

buildTool() 是一个工厂函数，它提供以下安全默认值：

  • 🔒 权限检查：自动添加权限检查逻辑
  • 📊 日志记录：自动记录工具调用
  • ⚠️ 错误处理：自动捕获和处理错误
  • ⏱️ 超时控制：自动设置超时限制

💡 优势

  • 🔌 易于扩展：添加新工具只需要实现 Tool 接口
  • 🔄 热更新：可以在运行时动态注册工具
  • 📊 统一管理：所有工具都在一个注册表中
  • 🛡️ 安全可控：每个工具都有权限检查
