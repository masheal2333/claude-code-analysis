🎯 概述

工具分发系统 是 Claude Code 的扩展性核心。它通过一个统一的注册和分发机制，让新工具可以轻松集成。

核心理念：

  • 📦 标准化接口：所有工具遵循相同的接口
  • 🔌 即插即用：注册即可使用，无需修改核心循环
  • 🛡️ 安全默认：buildTool() 工厂提供安全默认值
  • 📊 统一管理：工具的生命周期统一管理

🏗️ 架构设计

⚙️ 实现细节

Tool.ts - 工具接口定义

interface Tool {
    name: string;
    description: string;
    parameters: JSONSchema;
    execute: (params: any) => Promise;
}

interface ToolDefinition {
    name: string;
    description: string;
    parameters: JSONSchema;
    execute: (params: any) => Promise;
    permissions?: Permission[];
    timeout?: number;
}

buildTool() - 工具工厂

function buildTool(definition: ToolDefinition): Tool {
    return {
        name: definition.name,
        description: definition.description,
        parameters: definition.parameters,
        execute: async (params) => {
            // 1. 权限检查
            if (definition.permissions) {
                await checkPermissions(definition.name, params);
            }
            
            // 2. 超时控制
            if (definition.timeout) {
                return await executeWithTimeout(
                    definition.execute,
                    params,
                    definition.timeout
                );
            }
            
            // 3. 执行工具
            return await definition.execute(params);
        }
    };
}

📚 代码示例

注册自定义工具

// 1. 定义工具
const myTool: ToolDefinition = {
    name: "my_custom_tool",
    description: "这是一个自定义工具",
    parameters: {
        type: "object",
        properties: {
            input: { type: "string" }
        },
        required: ["input"]
    },
    execute: async (params) => {
        return { result: `处理: ${params.input}` };
    }
};

// 2. 注册工具
registerTool(myTool);

// 3. 工具现在可以被 Claude 使用了
