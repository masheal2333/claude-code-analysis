🎯 概述

知识按需加载 是 Claude Code 的核心创新。它通过 tool_result 注入知识，而不是放在系统提示中。

核心优势：

  • 💰 节省 Token：只在需要时加载，不占用系统提示
  • 🔄 动态更新：知识可以随时更新，无需重启
  • 🎯 精准加载：根据目录和上下文加载相关知识
  • 📦 模块化：知识被封装为独立的 Skill

⚡ vs System Prompt

特性 System Prompt 知识按需加载
加载时机 始终加载 按需触发
Token 消耗 每轮对话都消耗 仅执行时消耗
更新机制 需重启 热更新
作用域 全局 可限定目录/项目

⚙️ 实现细节

SkillTool - 知识加载工具

async function executeSkill(skillName: string) {
  // 1. 查找 Skill
  const skill = findSkill(skillName);
  
  // 2. 获取 Prompt 内容
  const prompt = await skill.getPromptForCommand();
  
  // 3. 通过 tool_result 注入
  return {
    type: "tool_result",
    content: prompt
  };
}

📄 CLAUDE.md 机制

CLAUDE.md 是 Claude Code 的项目级知识文件：

  • 📍 位置：项目根目录或子目录
  • 🔄 加载：进入目录时自动加载
  • 📝 内容：项目规范、构建命令、约定
  • 🎯 作用域：仅在该目录及子目录生效
