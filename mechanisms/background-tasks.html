🎯 概述

后台任务系统 允许 Claude 在后台执行耗时操作，同时保持主对话的响应能力。

核心特性：

  • 🔄 非阻塞：耗时操作在后台执行
  • 🔔 完成通知：任务完成时自动通知
  • 📊 进度跟踪：实时跟踪后台任务进度
  • ⚡ 并行执行：多个后台任务可以并行

⚙️ 实现细节

DreamTask - 后台任务

interface DreamTaskParams {
  task: string;
  callback?: (result: any) => void;
  timeout?: number;
}

async function executeDreamTask(params: DreamTaskParams) {
  // 1. 创建后台任务
  const taskId = generateTaskId();
  
  // 2. 启动守护线程
  startDaemonThread(taskId, async () => {
    // 3. 执行耗时操作
    const result = await executeLongRunningTask(params.task);
    
    // 4. 任务完成，注入通知
    await injectCompletionNotification(taskId, result);
    
    // 5. 调用回调函数
    if (params.callback) {
      params.callback(result);
    }
  });
  
  return taskId;
}

📚 使用示例

后台执行测试

// 1. 启动后台测试任务
const taskId = await executeDreamTask({
  task: "运行所有单元测试",
  callback: (result) => {
    console.log("测试完成:", result);
  }
});

// 2. 主对话可以继续处理其他任务
console.log("测试已在后台启动，任务 ID:", taskId);

// 3. 当测试完成时，会自动收到通知
