👥 机制 4: 子代理

"分解大任务；清理每个子任务的上下文"

← 返回首页 概述 实现细节 上下文隔离 使用示例

🎯 概述

子代理系统 允许 Claude 创建独立的子代理来处理特定任务。每个子代理有自己的消息历史，保持主对话干净。

核心特性：

  • 🔀 任务分解：将大任务拆分为小任务
  • 🧹 上下文隔离：子代理有独立的消息历史
  • 📊 结果聚合：子代理结果返回给主代理
  • ⚡ 并行执行：多个子代理可以并行工作

AgentTool - 子代理工具

interface AgentToolParams {
  task: string;           // 子代理任务描述
  context?: string;       // 额外上下文
  model?: string;         // 使用的模型
  maxTokens?: number;     // 最大 Token 数
}

async function executeAgentTool(params: AgentToolParams) {
  // 1. 创建新的消息历史
  const messages = [];
  
  // 2. 添加任务描述
  messages.push({
    role: "user",
    content: params.task
  });
  
  // 3. 创建子代理上下文
  const agentContext = createAgentContext({
    parentAgentId: currentAgentId,
    taskId: generateTaskId()
  });
  
  // 4. 执行子代理
  const result = await runAgent({
    messages,
    context: agentContext,
    model: params.model
  });
  
  return result;
}
from dataclasses import dataclass
from typing import Any, Dict, List, Optional

@dataclass
class AgentToolParams:
    task: str                    # 子代理任务描述
    context: Optional[str] = None  # 额外上下文
    model: Optional[str] = None    # 使用的模型
    max_tokens: Optional[int] = None  # 最大 Token 数

async def execute_agent_tool(params: AgentToolParams) -> Dict[str, Any]:
    # 1. 创建新的消息历史
    messages: List[Dict[str, str]] = []
    
    # 2. 添加任务描述
    messages.append({
        "role": "user",
        "content": params.task
    })
    
    # 3. 创建子代理上下文
    agent_context = create_agent_context(
        parent_agent_id=current_agent_id,
        task_id=generate_task_id()
    )
    
    # 4. 执行子代理
    result = await run_agent(
        messages=messages,
        context=agent_context,
        model=params.model
    )
    
    return result

🧹 上下文隔离

主代理
├── 消息历史: [msg1, msg2, msg3, ...]
├── 工具调用: [tool1, tool2, ...]
└── 状态: { ... }
    │
    ├── 子代理 1
    │   ├── 消息历史: [sub_msg1, sub_msg2, ...]  ← 独立！
    │   ├── 工具调用: [sub_tool1, ...]
    │   └── 状态: { ... }
    │
    └── 子代理 2
        ├── 消息历史: [sub_msg1, sub_msg2, ...]  ← 独立！
        ├── 工具调用: [sub_tool1, ...]
        └── 状态: { ... }

📚 使用示例

使用子代理处理多个文件

// 主代理可以创建多个子代理并行处理
const results = await Promise.all([
  // 子代理 1: 分析文件 A
  executeAgentTool({
    task: "分析 fileA.ts 的代码结构",
    context: "需要识别所有函数和类"
  }),
  
  // 子代理 2: 分析文件 B
  executeAgentTool({
    task: "分析 fileB.ts 的代码结构",
    context: "需要识别所有函数和类"
  })
]);
