🎯 概述

防护栏杆系统 是 Claude Code 的安全保障，确保代理行为在可控范围内。

核心功能：

  • 🔐 权限检查：每个工具调用都经过权限检查
  • 📦 沙箱隔离：危险操作在沙箱中执行
  • 🚫 安全边界：定义代理的行为边界
  • 📊 审计日志：记录所有关键操作

🔐 安全机制

权限检查

每个工具调用都必须通过权限检查：

  • ✅ 用户授权：用户明确授权的操作
  • ✅ 策略允许：符合安全策略
  • ✅ 风险评估：操作风险在可控范围

危险操作

以下操作需要额外确认：

  • ⚠️ 删除文件：需要用户确认
  • ⚠️ 执行命令：需要用户确认
  • ⚠️ 网络访问：需要用户授权

⚙️ 实现细节

permissions/ - 权限系统

interface PermissionCheck {
  tool: string;
  params: any;
  context: ToolUseContext;
}

async function checkPermissions(check: PermissionCheck) {
  // 1. 检查工具是否需要权限
  if (!requiresPermission(check.tool)) {
    return { allowed: true };
  }
  
  // 2. 检查用户是否已授权
  if (await hasUserAuthorization(check)) {
    return { allowed: true };
  }
  
  // 3. 检查安全策略
  const policy = await getSecurityPolicy();
  if (policy.allows(check)) {
    return { allowed: true };
  }
  
  // 4. 需要用户确认
  return {
    allowed: false,
    reason: "需要用户确认",
    confirmationRequired: true
  };
}
from dataclasses import dataclass
from typing import Any

@dataclass
class PermissionCheck:
    tool: str
    params: Any
    context: ToolUseContext

async def check_permissions(check: PermissionCheck) -> dict:
    # 1. 检查工具是否需要权限
    if not requires_permission(check.tool):
        return {"allowed": True}
    
    # 2. 检查用户是否已授权
    if await has_user_authorization(check):
        return {"allowed": True}
    
    # 3. 检查安全策略
    policy = await get_security_policy()
    if policy.allows(check):
        return {"allowed": True}
    
    # 4. 需要用户确认
    return {
        "allowed": False,
        "reason": "需要用户确认",
        "confirmation_required": True
    }

📚 使用示例

危险操作确认

// 当 Claude 尝试删除文件时
const result = await checkPermissions({
  tool: "file_delete",
  params: { path: "/important/file.txt" },
  context: currentContext
});

if (!result.allowed) {
  // 弹出确认对话框
  const confirmed = await showConfirmationDialog({
    title: "确认删除",
    message: "确定要删除 /important/file.txt 吗？",
    details: "此操作不可撤销"
  });
  
  if (!confirmed) {
    throw new Error("用户取消了操作");
  }
}
# 当 Claude 尝试删除文件时
result = await check_permissions(

    )
)

if not result["allowed"]:

        title="确认删除",

        details="此操作不可撤销"

    if not confirmed:
        raise RuntimeError("用户取消了操作")
