💾 机制 7: 持久化任务

"大目标 → 小任务 → 磁盘"

🎯 概述

持久化任务系统 是 Claude Code 的任务管理核心，它将复杂的工作分解为可管理的小任务，并将它们持久化到磁盘。

核心特性：

  • 📦 任务分解：将大目标拆分为小任务
  • 💾 状态持久化：任务状态保存到磁盘，支持重启恢复
  • 🔗 依赖管理：支持任务之间的依赖关系
  • 📊 进度跟踪：实时跟踪任务执行进度

⚙️ 实现细节

TaskCreate - 创建任务

interface TaskCreateParams {
  title: string;
  description?: string;
  priority?: 'high' | 'medium' | 'low';
  dependencies?: string[];  // 依赖的任务 ID
  estimatedTime?: number;   // 预估时间（分钟）
}

async function createTask(params: TaskCreateParams): Promise<Task> {
  // 1. 验证参数
  validateTaskParams(params);
  
  // 2. 生成唯一 ID
  const taskId = generateTaskId();
  
  // 3. 构建任务对象
  const task: Task = {
    id: taskId,
    title: params.title,
    description: params.description,
    status: 'pending',
    priority: params.priority || 'medium',
    dependencies: params.dependencies || [],
    createdAt: new Date(),
    updatedAt: new Date()
  };
  
  // 4. 持久化到磁盘
  await saveTaskToDisk(task);
  
  return task;
}

TaskUpdate - 更新任务状态

interface TaskUpdateParams {
  taskId: string;
  status?: 'pending' | 'in_progress' | 'completed' | 'blocked';
  progress?: number;  // 0-100
  notes?: string;
}

async function updateTask(params: TaskUpdateParams): Promise<Task> {
  // 1. 加载现有任务
  const existingTask = await loadTaskFromDisk(params.taskId);
  
  // 2. 检查状态转换是否合法
  validateStatusTransition(existingTask.status, params.status);
  
  // 3. 更新任务
  const updatedTask = {
    ...existingTask,
    ...params,
    updatedAt: new Date()
  };
  
  // 4. 保存到磁盘
  await saveTaskToDisk(updatedTask);
  
  // 5. 触发状态变更事件
  await emitTaskUpdateEvent(updatedTask);
  
  return updatedTask;
}

🔌 API 接口

TaskCreate

用途：创建新任务

参数：title, description, priority, dependencies

返回：Task 对象

TaskUpdate

用途：更新任务状态

参数：taskId, status, progress, notes

返回：更新后的 Task

TaskGet

用途：获取单个任务详情

参数：taskId

返回：Task 对象

TaskList

用途：列出所有任务

参数：filter, sort, limit

返回：Task[] 数组

📚 使用场景

场景 1: 大型重构任务

// 1. 创建主任务
const mainTask = await createTask({
  title: "重构用户认证模块",
  description: "将旧的 session-based 认证迁移到 JWT",
  priority: "high"
});

// 2. 创建子任务
const subTask1 = await createTask({
  title: "创建 JWT 工具类",
  dependencies: [mainTask.id]
});

const subTask2 = await createTask({
  title: "修改登录接口",
  dependencies: [subTask1.id]
});

// 3. 更新进度
await updateTask({
  taskId: subTask1.id,
  status: "in_progress",
  progress: 50
});

场景 2: 跨会话任务

任务持久化到磁盘意味着：

  • ✅ 重启 Claude Code 后可以继续
  • ✅ 不同会话可以协作处理同一任务
  • ✅ 任务历史可以追溯
