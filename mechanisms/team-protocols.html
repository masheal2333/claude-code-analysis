🎯 概述

团队协议 定义了代理团队之间的通信规则和协作模式。

核心特性：

  • 📋 标准化：统一的通信格式
  • 🔄 请求-响应：明确的交互模式
  • 🤝 协商机制：支持任务协商
  • 📊 状态同步：团队成员状态同步

📋 通信协议

请求格式:
{
  "type": "request",
  "from": "agent_a",
  "to": "agent_b",
  "action": "execute_task",
  "params": { ... },
  "timestamp": "2026-04-01T10:00:00Z"
}

响应格式:
{
  "type": "response",
  "from": "agent_b",
  "to": "agent_a",
  "requestId": "req_123",
  "status": "completed",
  "result": { ... },
  "timestamp": "2026-04-01T10:01:00Z"
}

  const message = {
    type: "request",
    from: currentAgentId,
    to: params.to,
    action: params.action,
    params: params.params,
    timestamp: new Date()
  };
  
  // 2. 发送到目标代理的邮箱
  await sendToMailbox(params.to, message);
  
  // 3. 等待响应
