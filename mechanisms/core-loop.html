🎯 概述

核心循环是 Claude Code 的心脏。它就是一个简单的 while(true) 循环，不断调用 Claude API，检查返回的 stop_reason，然后执行相应的操作。

核心逻辑：

  • 📤 发送消息给 Claude API
  • 🔍 检查 stop_reason
  • ✅ 如果是 stop，返回结果
  • 🔧 如果是 tool_use，执行工具并追加结果

💻 代码分析

src/query.ts - 核心循环实现

async function query(messages: Message[]): Promise {
    while (true) {
        // 1. 调用 Claude API
        const response = await claude.api.messages.create({
            model: "claude-3-opus-20240229",
            messages: messages,
            tools: toolDefinitions
        });
        
        // 2. 检查停止原因
        if (response.stop_reason === "stop") {
            // 3. 返回最终结果
            return response;
        } else if (response.stop_reason === "tool_use") {
            // 4. 执行工具
            const toolResult = await executeTool(response.tool_use);
            
            // 5. 将工具结果追加到消息历史
            messages.push({ 
                role: "tool", 
                content: toolResult 
            });
        }
    }
}

关键设计点

  • 极简设计：整个 Agent 系统的核心就是一个循环
  • 状态管理：通过 messages 数组维护对话历史
  • 工具执行：工具调用结果作为下一轮输入
  • 无限循环：直到收到 stop 响应才退出

🔄 执行流程

用户输入
    ↓
[调用 Claude API]
    ↓
检查 stop_reason
    ↓
┌─────────────────┐
│ stop_reason=stop │ → 返回最终结果
└─────────────────┘
    ↓
┌─────────────────────┐
│ stop_reason=tool_use │ → 执行工具
└─────────────────────┘
    ↓
[工具执行完成]
    ↓
[将结果追加到 messages]
    ↓
[继续循环]

💡 为什么这样设计？

设计哲学

这种设计体现了 "简单即美" 的工程哲学：

  • 🎯 聚焦核心：只关注最核心的循环逻辑
  • 🔄 可预测性：每次循环都是确定性的
  • 📈 可扩展性：工具可以随时添加，循环逻辑不变
  • 🐛 易调试：问题可以定位到具体某一轮循环
