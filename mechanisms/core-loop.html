🎯 概述

核心循环 是 Claude Code 的心脏。它是一个简单的 while-true 循环，不断调用 Claude API，检查停止原因，执行工具，然后继续。

核心思想：

  • 🔄 循环驱动：所有 Agent 行为都在循环中完成
  • 🛠️ 工具执行：当 Claude 返回 tool_use 时，执行工具并继续
  • 📊 状态管理：通过 messages 数组维护对话历史

💻 代码分析

query.ts - 核心循环实现

async function query(messages: Message[]): Promise<Response> {
    while (true) {
        // 1. 调用 Claude API
        const response = await claude.api.messages.create({
            model: "claude-3-opus-20240229",
            messages: messages,
            tools: toolDefinitions
        });
        
        // 2. 检查停止原因
        if (response.stop_reason === "stop") {
            // 3. 返回最终结果
            return response;
        } else if (response.stop_reason === "tool_use") {
            // 4. 执行工具
            const toolResult = await executeTool(response.tool_use);
            
            // 5. 将工具结果追加到消息历史
            messages.push({ 
                role: "tool", 
                content: toolResult 
            });
            
            // 6. 继续循环
            continue;
        }
    }
}

💡 意义

核心循环的简洁性是 Claude Code 的关键设计：

  • 🎯 单一职责：循环只负责调度，不关心具体任务
  • 🔄 无限扩展：通过添加工具，可以处理任何任务
  • 📊 状态清晰：messages 数组就是完整的状态
  • 🛠️ 易于调试：每一步都可以追踪和复现
