📋 机制 3: 规划模式

"没有计划的代理会漂移"

← 返回首页 概述 代码分析 工作流程 相关工具 优势

🎯 概述

规划模式 强制 Claude 先思考再行动。它将复杂任务分解为明确的步骤，然后按计划执行。

核心思想：

  • 🧠 先规划：进入规划模式，列出所有步骤
  • ✅ 后执行：按步骤执行，每完成一步就标记
  • 📊 可追踪：进度可视化，完成率翻倍

EnterPlanModeTool - 进入规划模式

class EnterPlanModeTool implements Tool {
    name = 'enter_plan_mode';
    description = 'Enter planning mode to break down complex tasks';
    
    async execute(params: PlanModeParams): Promise<ToolResult> {
        // 1. 分析任务复杂度
        const complexity = analyzeTaskComplexity(params.task);
        
        // 2. 生成步骤列表
        const steps = await generateSteps(params.task, complexity);
        
        // 3. 进入规划模式
        await this.context.enterPlanMode({
            task: params.task,
            steps: steps,
            currentStep: 0
        });
        
        return {
            content: `进入规划模式，已生成 ${steps.length} 个步骤`,
            metadata: { steps }
        };
    }
}

TodoWriteTool - 创建任务步骤

interface TodoItem {
    id: string;
    content: string;
    status: 'pending' | 'in_progress' | 'completed';
}

class TodoWriteTool implements Tool {
    name = 'todo_write';
    description = 'Create and manage task steps';
    
    async execute(params: TodoWriteParams): Promise<ToolResult> {
        const { action, todo_id, content } = params;
        
        switch (action) {
            case 'create':
                return await this.createTodo(content);
            case 'update':
                return await this.updateTodo(todo_id, content);
            case 'complete':
                return await this.completeTodo(todo_id);
            case 'reorder':
                return await this.reorderTodos(params.order);
        }
    }
    
    private async createTodo(content: string): Promise<TodoResult> {
        const todo: TodoItem = {
            id: generateId(),
            content,
            status: 'pending'
        };
        await this.saveTodo(todo);
        return { content: `创建任务: ${content}` };
    }
}
from dataclasses import dataclass
from enum import Enum
from typing import List, Optional

class TodoStatus(Enum):
    PENDING = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETED = "completed"

@dataclass
class TodoItem:
    id: str
    content: str
    status: TodoStatus

class TodoWriteTool:
    name = "todo_write"
    description = "Create and manage task steps"
    
    async def execute(self, params: dict) -> dict:
        action = params.get("action")
        todo_id = params.get("todo_id")
        content = params.get("content")
        
        if action == "create":
            return await self.create_todo(content)
        elif action == "update":
            return await self.update_todo(todo_id, content)
        elif action == "complete":
            return await self.complete_todo(todo_id)
        elif action == "reorder":
            return await self.reorder_todos(params.get("order"))
    
    async def create_todo(self, content: str) -> dict:
        todo = TodoItem(
            id=str(uuid.uuid4()),
            content=content,
            status=TodoStatus.PENDING
        )
        await self.save_todo(todo)
        return {"content": f"创建任务: {content}"}

💡 优势

  • 📈 完成率翻倍：有计划的任务完成率更高
  • 👁️ 透明度：用户可以看到完整计划
  • 🔄 可恢复：中断后可以从断点继续
  • 🎯 聚焦：避免任务漂移
