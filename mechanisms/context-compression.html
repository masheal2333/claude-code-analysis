🎯 概述

上下文压缩 是 Claude Code 的内存管理机制。当对话历史太长时，它会自动压缩以释放空间。

核心思想：

  • 💭 上下文窗口有限：Claude 的上下文窗口是有限的（如 200K tokens）
  • 📈 对话会增长：每轮对话都会增加历史记录
  • 🗜️ 智能压缩：在不丢失关键信息的前提下压缩历史

压缩系统架构

📝 AutoCompact (自动摘要) 详解

🎯 核心原理

使用 LLM 生成对话摘要，保留关键信息，压缩详细内容。

🔄 工作流程

graph LR A[对话历史] --> B[检测 Token 使用] B --> C{超过阈值?} C -->|否| D[继续对话] C -->|是| E[提取待压缩消息] E --> F[调用 LLM 生成摘要] F --> G[保留系统消息] G --> H[替换为摘要] H --> I[继续对话]

💻 实现代码

// services/compact/autoCompact.ts

interface AutoCompactConfig {
  threshold: number;        // Token 阈值（默认 0.8）
  maxSummaryTokens: number; // 摘要最大 Token 数
  preserveSystem: boolean;  // 是否保留系统消息
}

async function autoCompact(
  messages: Message[],
  config: AutoCompactConfig
): Promise {
  // 1. 计算当前 Token 使用量
  const tokenCount = countTokens(messages);
  const maxTokens = getModelContextLimit();
  
  // 2. 检查是否需要压缩
  if (tokenCount / maxTokens < config.threshold) {
    return messages; // 不需要压缩
  }
  
  // 3. 提取待压缩的消息（排除系统消息）
  const toCompress = messages.filter(m => m.role !== 'system');
  const systemMessages = messages.filter(m => m.role === 'system');
  
  // 4. 调用 LLM 生成摘要
  const summaryPrompt = `
    请将以下对话压缩为简洁的摘要，保留：
    1. 用户的核心需求
    2. 已完成的关键任务
    3. 重要的决策和结论
    4. 待完成的任务
    
    对话内容：
    ${toCompress.map(m => `${m.role}: ${m.content}`).join('\n')}
  `;
  
  const summary = await callLLM({
    model: 'claude-3-haiku', // 使用轻量模型生成摘要
    maxTokens: config.maxSummaryTokens,
    messages: [{ role: 'user', content: summaryPrompt }]
  });
  
  // 5. 构建压缩后的历史
  return [
    ...systemMessages,
    {
      role: 'assistant',
      content: `[对话摘要]\n${summary}\n\n[压缩时间: ${new Date().toISOString()}]`
    }
  ];
}

✂️ SnipCompact (智能修剪) 详解

🎯 核心原理

删除已完成的工具调用结果，保留工具调用的摘要信息。

🔄 工作流程

graph LR A[工具调用完成] --> B[标记为可修剪] B --> C{Token 压力大?} C -->|否| D[保留完整结果] C -->|是| E[提取关键信息] E --> F[删除详细输出] F --> G[保留摘要]

💻 实现代码

// services/compact/snipCompact.ts

interface SnipableToolResult {
  toolName: string;
  originalSize: number;
  summary: string;
  canSnip: boolean;
}

async function snipCompact(
  messages: Message[]
): Promise {
  const result: Message[] = [];
  
  for (const msg of messages) {
    if (msg.role === 'tool') {
      // 1. 检查工具结果是否可以修剪
      const snipable = analyzeToolResult(msg);
      
      if (snipable.canSnip && snipable.originalSize > 1000) {
        // 2. 生成摘要
        const summary = generateToolSummary(msg);
        
        // 3. 替换为摘要
        result.push({
          role: 'tool',
          content: `[原始输出已修剪，共 ${snipable.originalSize} 字符]\n${summary}`
        });
      } else {
        result.push(msg);
      }
    } else {
      result.push(msg);
    }
  }
  
  return result;
}

function analyzeToolResult(msg: ToolMessage): SnipableToolResult {
  const content = msg.content;
  
  // 检查是否是文件读取、命令执行等可修剪的工具
  const snippableTools = ['read_file', 'execute_command', 'search'];
  const toolName = extractToolName(msg);
  
  return {
    toolName,
    originalSize: content.length,
    summary: '',
    canSnip: snippableTools.includes(toolName)
  };
}

🗜️ ContextCollapse (上下文折叠) 详解

🎯 核心原理

折叠已完成的子代理任务，将详细的执行过程压缩为简洁的结果。

🔄 工作流程

graph LR A[子代理任务完成] --> B[收集执行历史] B --> C[提取关键结果] C --> D[生成折叠摘要] D --> E[替换详细历史] E --> F[保留摘要]

💻 实现代码

// services/compact/contextCollapse.ts

interface SubAgentTask {
  taskId: string;
  task: string;
  messages: Message[];
  result: any;
  status: 'completed' | 'failed';
}

async function contextCollapse(
  mainMessages: Message[],
  subAgentTasks: SubAgentTask[]
): Promise {
  const result: Message[] = [];
  
  for (const msg of mainMessages) {
    // 1. 检查是否是子代理任务的消息
    const isSubAgentMsg = subAgentTasks.some(task => 
      task.messages.some(m => m.id === msg.id)
    );
    
    if (isSubAgentMsg) {
      // 2. 找到对应的子代理任务
      const task = subAgentTasks.find(t => 
        t.messages.some(m => m.id === msg.id)
      );
      
      // 3. 只保留第一条和最后一条消息（任务描述和结果）
      const isFirstMsg = task.messages[0].id === msg.id;
      const isLastMsg = task.messages[task.messages.length - 1].id === msg.id;
      
      if (isFirstMsg) {
        result.push(msg); // 保留任务描述
      } else if (isLastMsg) {
        // 替换为折叠摘要
        result.push({
          role: 'assistant',
          content: `[子代理任务完成]\n任务: ${task.task}\n状态: ${task.status}\n结果: ${JSON.stringify(task.result).substring(0, 200)}...`
        });
      }
      // 中间的详细消息被丢弃
    } else {
      result.push(msg);
    }
  }
  
  return result;
}

services/compact/ - 压缩服务架构

// services/compact/index.ts

// 1. 压缩策略接口
interface CompressionStrategy {
  name: string;
  priority: number;  // 优先级，数字越小优先级越高
  shouldCompress: (context: CompressionContext) => boolean;
  compress: (messages: Message[]) => Promise;
}

// 2. 压缩上下文
interface CompressionContext {
  tokenCount: number;
  maxTokens: number;
  messageCount: number;
  hasSubAgentTasks: boolean;
  hasToolResults: boolean;
}

// 3. 压缩管理器
class CompressionManager {
  private strategies: CompressionStrategy[] = [];
  
  registerStrategy(strategy: CompressionStrategy) {
    this.strategies.push(strategy);
    this.strategies.sort((a, b) => a.priority - b.priority);
  }
  
  async compress(messages: Message[]): Promise {
    const context = this.buildContext(messages);
    
    // 按优先级尝试压缩策略
    for (const strategy of this.strategies) {
      if (strategy.shouldCompress(context)) {
        console.log(`使用压缩策略: ${strategy.name}`);
        return await strategy.compress(messages);
      }
    }
    
    return messages; // 没有策略触发
  }
  
  private buildContext(messages: Message[]): CompressionContext {
    return {
      tokenCount: countTokens(messages),
      maxTokens: getModelContextLimit(),
      messageCount: messages.length,
      hasSubAgentTasks: messages.some(m => m.role === 'tool' && m.content.includes('subagent')),
      hasToolResults: messages.some(m => m.role === 'tool')
    };
  }
}

// 4. 注册压缩策略
const compressionManager = new CompressionManager();

compressionManager.registerStrategy({
  name: 'autoCompact',
  priority: 1,  // 最高优先级
  shouldCompress: (ctx) => ctx.tokenCount / ctx.maxTokens > 0.8,
  compress: autoCompact
});

compressionManager.registerStrategy({
  name: 'contextCollapse',
  priority: 2,
  shouldCompress: (ctx) => ctx.hasSubAgentTasks,
  compress: contextCollapse
});

compressionManager.registerStrategy({
  name: 'snipCompact',
  priority: 3,
  shouldCompress: (ctx) => ctx.hasToolResults,
  compress: snipCompact
});
