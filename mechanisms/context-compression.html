📦 机制 6: 上下文压缩

"上下文满了；腾出空间"

🎯 概述

上下文压缩 是 Claude Code 的内存管理机制。当对话历史太长时，它会自动压缩以释放空间。

核心策略：

  • 📝 自动摘要：将长对话压缩为摘要
  • ✂️ 智能修剪：删除不重要的历史
  • 🗜️ 上下文折叠：折叠已完成的子任务

📊 压缩策略

1. AutoCompact (自动摘要)

原理：使用 LLM 生成对话摘要

触发：Token 使用达到阈值

效果：保留关键信息，压缩详细内容

2. SnipCompact (智能修剪)

原理：删除已完成的工具调用结果

触发：工具调用完成后

效果：减少冗余信息

3. ContextCollapse (上下文折叠)

原理：折叠已完成的子代理任务

触发：子代理任务完成

效果：保持主对话简洁

⚙️ 实现细节

services/compact/ - 压缩服务

interface CompressionStrategy {
  name: string;
  shouldCompress: (context: Context) => boolean;
  compress: (messages: Message[]) => Promise;
}

// 注册压缩策略
registerCompressionStrategy({
  name: "autoCompact",
  shouldCompress: (context) => {
    return context.tokenCount > THRESHOLD;
  },
  compress: async (messages) => {
    // 使用 LLM 生成摘要
    const summary = await generateSummary(messages);
    return [{
      role: "system",
      content: `对话摘要: ${summary}`
    }];
  }
});

⚡ 触发条件

  • 📊 Token 阈值：当 Token 使用达到 80% 时触发
  • ✅ 任务完成：子任务完成后折叠上下文
  • 🔄 定期压缩：每 N 轮对话后自动压缩
  • 💾 内存不足：系统内存不足时触发
