🎯 什么是 Skills？

Skills 是 Claude Code 的核心扩展机制，它允许：

  • 📦 模块化知识 - 将特定领域的知识封装为独立模块
  • 🔄 按需加载 - 仅在需要时注入上下文，节省 Token
  • 🔌 动态扩展 - 支持本地文件、MCP 服务、远程市场
  • 🛠️ 工具化执行 - 通过 Tool 系统统一管理执行

Skills vs System Prompt 的区别

特性 System Prompt Skills
加载时机 始终加载 按需触发
Token 消耗 每轮对话都消耗 仅执行时消耗
更新机制 需重启 热更新
作用域 全局 可限定目录/项目

// src/skills/bundledSkills.ts
interface SkillConfig {
  name: string;
  description: string;
  whenToUse: string;
  userInvocable: boolean;
  getPromptForCommand: (args?: string) => Promise<ContentBlock[]>;
}

function registerBundledSkill(config: SkillConfig) {
  // 注册到全局 Skill 注册表
  skillRegistry.set(config.name, {
    type: 'prompt',
    ...config
  });
}

3. Skill 执行流程

// src/tools/SkillTool/SkillTool.ts
async function executeForkedSkill(
  command: Command,
  args: string | undefined,
  context: ToolUseContext
): Promise<ToolResult> {
  // 1. 获取 Prompt 内容
  const prompt = await command.getPromptForCommand(args);
  
  // 2. 创建隔离的子代理上下文
  const agentId = createAgentId();
  
  // 3. 在子代理中执行
  const result = await runAgent({
    agentId,
    messages: [createUserMessage(prompt)],
    context
  });
  
  return result;
}

📚 实际案例分析

案例 1: 内置 Skill - remember

用途： 记忆管理，将自动记忆条目整理到 CLAUDE.md

// src/skills/bundled/remember.ts
registerBundledSkill({
  name: 'remember',
  description: 'Review auto-memory entries...',
  whenToUse: 'Use when user wants to review memory',
  userInvocable: true,
  isEnabled: () => isAutoMemoryEnabled(),
  async getPromptForCommand(args) {
    let prompt = SKILL_PROMPT;
    if (args) {
      prompt += `\n## Additional context\n\n${args}`;
    }
    return [{ type: 'text', text: prompt }];
  }
});

案例 2: 目录触发器 (CLAUDE.md)

原理： 检测到目录中的 CLAUDE.md 时自动加载相关 Skill

// src/skills/loadSkillsDir.ts
async function loadMarkdownFilesForSubdir(
  dir: string
): Promise<MarkdownFile[]> {
  // 1. 扫描 .claude/skills/ 目录
  const files = await fs.readdir(dir);
  
  // 2. 解析 Frontmatter
  for (const file of files) {
    const content = await fs.readFile(file);
    const { data, content: body } = parseFrontmatter(content);
    
    // 3. 注册为 Skill
    registerSkill({
      name: data.name,
      description: data.description,
      prompt: body
    });
  }
}

🔍 Skill 发现机制

1

静态扫描

启动时扫描以下位置：

  • ~/.claude/skills/ (全局)
  • .claude/skills/ (项目级)
  • Bundled Skills (内置)
2

动态触发

运行时事件触发：

  • 目录切换时重新扫描 CLAUDE.md
  • MCP 服务连接时加载远程 Skills
  • 用户手动安装市场 Skill
3

智能推荐
