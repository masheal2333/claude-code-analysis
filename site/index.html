🎯 什么是 Harness Engineering？

Harness Engineering 是构建生产级 AI Agent 的核心工程实践。它不仅仅是让 AI 能执行任务，而是要确保 AI 在执行过程中：

  • 🛡️ 安全可控 - 权限管理、沙箱隔离
  • 📊 可监控 - 任务跟踪、性能监控
  • 🔄 可恢复 - 错误处理、状态持久化
  • 📈 可扩展 - 模块化设计、插件系统
  • 👥 可协作 - 多代理、团队协作

💻 实现分析

1. 核心循环 (query.ts)

async function query(messages: Message[]): Promise {
    while (true) {
        const response = await claude.api.messages.create({
            model: "claude-3-opus-20240229",
            messages: messages,
            tools: toolDefinitions
        });
        
        if (response.stop_reason === "stop") {
            return response;
        } else if (response.stop_reason === "tool_use") {
            const toolResult = await executeTool(response.tool_use);
            messages.push({ role: "tool", content: toolResult });
        }
    }
}

2. 工具注册 (Tool.ts)

interface Tool {
    name: string;
    description: string;
    parameters: JSONSchema;
    execute: (params: any) => Promise;
}

function buildTool(definition: ToolDefinition): Tool {
    return {
        name: definition.name,
        description: definition.description,
        parameters: definition.parameters,
        execute: async (params) => {
            // 权限检查
            await checkPermissions(definition.name, params);
            // 执行工具
            return await definition.execute(params);
        }
    };
}
